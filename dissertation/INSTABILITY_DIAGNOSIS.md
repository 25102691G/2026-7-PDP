# Uniform / PDP 高标准差：已有证据诊断

日期：2026-11-10。当前目标是解释不稳定性，不要求 PDP 优于 Uniform1 或贴近 Uniform4。按研究者指示，大规模确认结果退出当前论文，相关后续实验停止。本报告仅使用原固定 seeds0..4 的100条结果、历史诊断和源码。历史实验文件未删除；论文范围调整不是宣布旧实验无效，也不是选择优胜结果。

本轮真实训练0次、模型推理0次、新随机实验0次；不读训练/测试图、checkpoint、秘密随机状态，不改算法、隐私会计或超参数。

## 1. 首先确认：SD高是否计算错误？

**VERIFIED**：逐条读取U5 `PER_SEED_RECHECK.csv`索引的100份原final_evaluation，核对Spread/Coverage及冻结CELF。20格均恰好5条、seed集合0..4，样本SD分母4。每条attempt1/failure0/retry0/unexecuted0。当前Table6.1取完整5条，不取SE、组均值的SD或有利子集。

**DESCRIPTIVE**：LastFM PDP v2五次Coverage依次80.693459、91.725768、19.700552、93.223010、97.478329%，均值76.564224%、样本SD32.385626pp。19.700552%这一条占总离均差平方和77.0735%。这仅解释SD的算术构成，不解释训练为何产生该条，也不授权剔除它。

其他例子：Bitcoin Uniform1为33.135392、78.087886、96.080760、92.517815、68.171021%，SD25.250088pp；Facebook Uniform4为89.768768、52.138106、44.726006、89.800443、96.262274%，SD24.121426pp。后者不只一个较低结果。完整20格含样本方差、极值、低尾和五次值，见本目录audit/revision_20261110_five_seed_stability/five_seed_statistics.csv。

固定同格的CELF不变，Coverage=Spread的固定倍数；固定模型/图的一步IC p=1评价无Monte Carlo扩散随机性。标准差不能归因于分母变动或同一模型多次扩散评价。

## 2. 首要有证据的来源：Gaussian驱动的完整训练路径

**VERIFIED（条件效应）**：历史G2对12对运行固定初态、外层保留图、slot缓存和100步batch，仅更换fresh Gaussian源。此次重新检查12份z1 diagnostics中的paired_initial_states_equal、paired_caches_equal、paired_batch_steps_equal、distinct_noise_source及100次调用，全部符合保存的控制说明；没有重放秘密路径。

- LastFM init2/h0：96.847912% → 50.118203%，差−46.729708pp，Top50重合14%。
- Facebook init1/h0：72.632246% → 93.031359%，差+20.399113pp。
- Bitcoin对应条件下的变化较小，完整12对在U4 G2_INDEPENDENT_SCALAR_RECHECK.json。

所以固定公开初始化和外层图仍可能有很大的效用差，不能把所有不稳定称为“初始化seed不好”或“Bernoulli抽样不好”。但G2是历史有限条件下的受控证据，并非目前四配置全五图的方差贡献估计。噪声改变后续状态及其梯度，识别的是完整Gaussian驱动路径的条件效应，不能声称只测了直接加性噪声作用或已经识别总体主因。

## 3. 为什么这种路径敏感值得优先关注？

**VERIFIED（源码/公开常数）**：`experiments/node_dp_slots/aggregation.py`对每位置梯度和每slot合计二次裁剪，每slot范数≤3、4slot合计S范数≤12。`mechanism.py:update`的原更新为theta←theta−.005(S+Z)/16，噪声施加在全2340坐标；投影仅作用末32weight，bias和初始化不投影。

|配置|sigma_sum|每坐标每步噪声SD|每步噪声L2 RMS|每步信号位移范数上界|
|---|---:|---:|---:|---:|
|Uniform1|486|0.151875|7.346732|0.003750|
|PDP v2|260|0.081250|3.930351|0.003750|
|Uniform4|139|0.0434375|2.101226|0.003750|

每坐标噪声SD=lr*sigma/B，L2 RMS=sqrt(E||lr*Z/B||²)=sqrt(2340)*lr*sigma/B。均为投影前、理想噪声的公开尺度；信号范数界不是邻接敏感度推导的替代，即使两者此处数值恰好都为12。

**HYPOTHESIS**：受限信号与大尺度随机更新的组合可能让不同训练轨迹进入不同表示/排名状态，从而产生偶发严重低效用。这一机制解释有尺度和历史控制的支持，应优先排查。

**限制**：没有四配置完整逐步有用梯度方向、每层/函数响应和噪声后自适应抵消量，不能报告“噪声占方差X%”。参数空间RMS不是logit误差或Coverage SD，信号界不是实测SNR；不能用100步sqrt(T)加性参照当真实终态误差。不同参数方向的功能敏感性不同。

## 4. 哪些说法可以排除或限制？

|说法|现有证据判断|
|---|---|
|都由PDP外层Bernoulli导致|不是共同必要原因：Uniform没有外层Bernoulli仍不稳定，G2固定保留图仍有大差。Bernoulli对PDP的额外贡献未识别。|
|Gaussian越小，任何图的SD必然越小|不成立为现有样本的单调描述；sigma139的Bitcoin SD0.731、Facebook SD24.121。同sigma跨图差异不能识别具体拓扑原因。|
|都是Top50边界平分或sigmoid饱和导致|缺少统一支持：原排名用pre-sigmoid；U4保存的100条排名审计均logits有限、所选零出度数0；大边界并列的一个Email Uniform1结果反而高效用。历史若干严重低例无并列且部分间隙很大。|
|是Coverage分母或扩散Monte Carlo误差|固定格分母恒定，评价p1/一步确定；此次原标量全部核对一致。|
|SD高就证明实现bug或隐私保证失效|不能这样推断。当前未定位新的具体实现缺陷；静态一致性也不等于排除全部bug或机器DP认证。|
|5seed平均后能消除单次不稳定|不能。SD应取5次单次结果之间的离散度；重复均值的SE或组均值SD是另一对象。|

## 5. 排名与损失是可能的中间环节，尚非已定位根因

**VERIFIED**：全部层/attention参数均被加噪；仅末32weight非负约束不能保证隐藏表示稳定。原loss是在采样训练子图上的连续覆盖乘积项+0.5选择惩罚；评价是测试图硬Top50和邻域并集，目标不相同。所选节点的单点传播能力与集合重叠共同决定Spread。

**HYPOTHESIS**：噪声通过非线性层改变表示，连续surrogate与硬排序/训练测试迁移间的差异使参数路径变化转化成Coverage差。即使选中高出度节点，邻域重叠也可能让集合覆盖较差。

**UNRESOLVED**：哪一层、哪段训练、覆盖项/正则项梯度、隐藏激活、排名翻转或邻域冗余主导？现有证据不能分摊它们的因果贡献。G1终态饱和或参数位移也不能倒推出训练期“梯度死亡”。历史New Matched同时改变冻结空间、梯度裁剪几何和秘密路径，其较低SD不是只改变维数的因果证据；G3/C3失败也不能当作有效稳定器。

## 6. 当前结论与边界

已能解释的是：五条结果中出现严重低效用轨迹直接拉大样本SD；Gaussian驱动的自适应训练路径可以在固定初态/保留图条件下产生很大的Coverage差；共同训练核的信号/噪声尺度为优先调查路径敏感提供了具体依据。

尚不能定论的是：Gaussian、初始化、Bernoulli、图结构、表示和离散排名分别解释多少方差，或哪一个设计改动能可靠解决问题。普通5seed的公开初始化和秘密路径同时变化，不能拆分贡献。当前不实施降低噪声、增加训练步数、更换种子、参数平均、修改裁剪或任何v3；相关改变既影响效用也可能影响隐私证明，不能凭猜测操作。

本轮到已有证据诊断为止，不安排大规模测试，也不以显著优胜为停止条件。若将来需要新的干预，应另定问题和范围；本报告不是新实验授权。
