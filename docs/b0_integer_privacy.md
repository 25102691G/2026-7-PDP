# B0：整数梯度与精确离散高斯训练机制

状态：实现规范与证明；不是对原 PrivIM 或既有 checkpoint 的追认。
原始论文仍按 AGENTS.md 的 SHA-256 使用。本机制保留其 Algorithm 2 的
每子图裁剪、求和、加噪、固定 B 平均和固定 T 更新，以及 Equation (5) 损失。
与原文的有意差异：不用 Equation (7)/(8) 的出现次数会计；
梯度先映射到整数球，在整数域加独立离散高斯，再做浮点优化器后处理。
这样消除“浮点高斯采样近似被直接视为精确高斯”的实现缺口。

保护起点、无界节点增删定义、可信环境和发布合同沿用
[P0 定义](pdp_privacy_design.md)。下文的范围证明不依赖子图稳定性。

## 1. 公共配置和输入域

公开固定 B≥1、T≥1、参数维度 d、格点间距 h=2^-k、
整数梯度球半径 R≥1、噪声尺度 s∈N、目标 epsilon>0、0<delta<1，
以及模型架构、初始化和学习率日程。选 R=floor(C/h)，故 Rh≤C。
有效输入包含空图、孤立节点、无边图、任意有效诱导图；
内层选择器最多返回 B 项，不足补零。
这些公共量不能从一次实际采样的节点/子图数量重新校准。

有限精度求出的任意梯度向量（包括私有状态不同导致的不同值）先执行 Q：

1. 非有限向量映射为零。
2. 近似裁剪并量化，得到 Python 任意精度整数向量 j。
3. 用整数平方和精确检查 ||j||²≤R²；如果越界，用
   L=ceil(sqrt(sum j_i²))，逐坐标向零舍入 j_i*R/L。

最后一步用整数乘除与整数平方根，因而无浮点误差假设。
对每坐标均有 |j'_i|≤|j_i|R/L，故 ||j'||²≤R²。
前两步的浮点误差至多改变选到球内哪个点，不会改变证明中的球半径。
空输入、失败的内部子图选择和非有限梯度都是零贡献；
这些分支不得作为额外可见的日志/错误/文件缺失导出。

## 2. 整数域敏感度

第 t 步的信号 a_t 是至多 B 个 Q 梯度的整数和：

~~~text
||a_t||≤BR；
任意两输入及其任意私有内部状态：||a_t-a'_t||≤2BR。
~~~

按坐标独立采样 Z_i∈Z，质量函数正比于 exp(-Z_i²/(2s²))；
先用 Python 整数完成 Y_t=a_t+Z_t，之后才能转换浮点并除 B、乘 h。
不能把整数噪声先转换浮点再加到未量化梯度上，那不是本机制。

## 3. 一步及训练级双向保证

设 D_s(m) 是整数中心 m、尺度 s 的离散高斯。
对整数 u,v 以及 alpha>1，有

~~~text
D_alpha(D_s(u)||D_s(v))≤alpha*(u-v)²/(2s²)。
~~~

直接展开似然比并配方，除了 alpha*(u-v)²/(2s²) 外，
剩余项为移位高斯格点归一化常数相对于整数中心常数的对数比，
后者不大于零。归一化常数在整数中心最大，可由 Poisson 求和的非负余弦系数证明。
这也覆盖交换 u,v 的方向。多坐标的散度相加。
该事实对应 Canonne–Kamath–Steinke 的 Proposition 5。

即使此前历史使两侧隐藏容器的后验分布不同，取两个条件信号分布的乘积
作为共同混合索引，使用与 P0 路线 B 相同的联合分布—边缘化论证，
仍得到每步双向条件 RDP：

~~~text
r_t(alpha)≤alpha*(2BR)²/(2s²)。
T 步 rho=T*(2BR)²/(2s²)；
epsilon_cert≤rho+2sqrt(rho*log(1/delta))。
~~~

这里的 R、s 都以格点为单位。实际梯度和的物理噪声尺度是 hs；
固定 B 均值侧为 hs/B。不能再乘出现率或进行一次额外的子图放大。
选择器可继续内部使用 SCS/BES，既不公开私有采样结果，也不假设只改变 M 项。

Q 之后的噪声采样和整数加法必须精确。其后的转换、截断、模型投影、
SGD 更新和参数保存可以是任意固定的数值后处理。
特别地，对 Y_t 先按公开范围截断再转换浮点，可以避免极端整数转浮点溢出，
而不破坏隐私；不允许在原始梯度上执行同样操作后省略证明所要求的整数球检查。
模型的任何可公开缓冲区只能是公共初始化和 Y_1:T 的函数。

## 4. 精确噪声和随机源

采样使用有理数 Bernoulli(exp(-x))、整数双边几何建议分布和拒绝采样；
判断只包含整数和 Fraction 算术，不计算近似 exp、log 或浮点正态分位数。
这采用 CKS Algorithms 1–3 的算法思想，独立实现，不拷贝其作者代码。
拒绝采样几乎必然终止；不能给它加一个“达到迭代上限便返回零”的分支。
采样耗时和内部拒绝次数不属于允许公开的输出。

生产路径只使用 secrets.randbelow/SystemRandom 所依赖的系统安全随机位，
无可公开复现的噪声 seed 参数。定理采用秘密、独立、无偏随机位模型；
系统随机源满足该模型是部署的标准信任前提，不把固定 PRNG seed 当作随机秘密。
测试可以替换底层均匀位以验证控制流，但此类测试运行不构成私有发布。

## 5. 保守数值标定

rho 是整数之比。实现使用 Decimal 的向上舍入计算 rho 上界；
-ln(delta) 使用正确舍入结果的 next_plus 上包络，
sqrt 同样使用 next_plus 上包络，再向上计算 epsilon_cert。
对公共整数 s 做搜索，只有 epsilon_cert_upper≤目标才接受。
这避免仅依赖一个浮点近似、一个有限 alpha 网格或一次实际 m 的反解。
Decimal 的 ln/sqrt 正确舍入语义来自 Python 官方文档。

证书只记录公共配置、s、rho 和上界，不包含实际容器大小、节点频率、
原始 loss、样本 hash 或噪声种子。固定维度参数文件是唯一数据相关公开产物。
训练诊断如有需要，只能放在明确的可信内部目录。

## 6. PDP 接入关口

B0 实现通过整数球检查、固定 T、空图、非有限贡献、独立噪声、
参数专用导出和回退行为的代码核验后，才允许调用
[已证明的外层节点抽样](p0_pdp_feasibility.md)。
每个节点必须另外满足 p_v*delta_0≤delta_v；共同 delta 只是特例。
本文件不改变 P0 关于“旧 PrivIM* 不能直接认证”的历史结论。

实现中的外层概率选为不大于以下界的有理数：

~~~text
p_v ≤ min(1, (exp(epsilon_v)-1)/(exp(epsilon_0)-1), delta_v/delta_0)。
~~~

对指数比做向下包络，再向下取到 2^-64 格点；delta 比以 Fraction 精确计算。
用 secrets.randbelow(分母)<分子执行精确 Bernoulli。
由于 P0 的双向证明对任何 p∈[0,1] 成立，且 epsilon_bound 随 p 单调，
向下取整只会增强保护，同时精确保证 p_v*delta_0≤delta_v。
这也是共同 delta 情形原公式的保守实现，而非用近似浮点概率冒称精确等式。
epsilon_v=0 或 delta_v=0 时取 p_v=0；epsilon_v≥epsilon_0 且
delta_v≥delta_0 时允许 p_v=1。

首个 B0 核验关口：隔离 CPU 环境 PyTorch 2.1.1+cpu、DGL 2.0.0、
igraph 0.11.5，原有与新增测试共 83 项通过。检查包含实际 GRAT/Equation (5)
产生非零贡献、空/孤立图、固定 T、预处理失败回退、整数加噪顺序、
可信警告边界和参数专用导出。测试验证实现对应关系，不替代上述证明，
也不认证旧 PrivIM 的出现次数会计。
