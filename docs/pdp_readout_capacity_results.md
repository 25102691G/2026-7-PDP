# 固定读出模型的 Coverage 上界：确认后的只读诊断

本报告不新增训练、不修改测试协议、不选择测试 seed，也不把最优测试集合当作
可部署方法。它解释最后一轮正值编码器模型的限制，不能替代隐私证明。

## 范围与推导

固定最后一轮使用的公开编码器、五个公开模型 seed、32 维读出权重盒、
偏置盒和原六个公开目标图。读出前特征不随私有读出参数改变。对任意两个
节点，用逐坐标端点得到读出分数差的下界，并用向外舍入及确定性 FP32
误差包络处理实际线性层；证明与算术假设见
[区间设计](pdp_readout_interval_design.md)。不假定近似相等的特征严格相等。

以公开初始化的 Top-50 为参照：若外部节点被这 50 个节点全部严格支配，
它不可能进入任何盒内读出的 Top-50；留下候选池 P。若参照集合中的节点
严格支配所有外部节点，它属于任何读出的 Top-50；这些节点组成核心 C。
因此所有实际输出满足 C⊆Top-50⊆P。

穷举 P 中包含 C 的 50 节点子集，计算一步 IC(p=1) 的闭出邻域并集大小。
这放宽了“能否由同一个线性读出实现”的限制，所得最优覆盖是乐观上界，
不是可达到的结果，也没有生成或保存测试优化的读出参数。
全部 30 个情况仅需穷举 14,029 个组合，均完成精确整数计数，没有触发
候选并集的宽松回退。候选池有 51–58 个节点，固定核心有 43–49 个节点。

## 结果

Coverage 均为与原实验相同 CELF 分母的百分比；上界对五个固定模型 seed
分别成立，下表再取均值。展示值四舍五入到六位小数；严格上界比较采用
所链接 JSON 中的整数比与有理数，不把四舍五入值当作向上舍入的证书。

| 数据集 | 公开初始化 | 当前 Node-PDP | 盒内家族的乐观上界 |
|---|---:|---:|---:|
| Email | 93.055556 | 93.055556 | 93.518519 |
| Bitcoin | 98.396675 | 98.361045 | 98.871734 |
| LastFM | 94.877857 | 94.877857 | 94.956659 |
| HepPh | 81.390006 | 81.390006 | 82.033314 |
| Facebook | 89.059233 | 89.059233 | 92.157111 |
| Gowalla | 96.817180 | 96.817180 | 97.283584 |
| 六数据集等权均值 | 92.266084 | 92.260146 | **93.136820** |

用整数 spread 和 CELF 分母重新做有理数计算得到：

- 六数据集上，相对当前 PDP 的最大剩余宏平均改进 ≤0.876674 个百分点；
  相对已完成的低参与统一 DP 对照 ≤0.847507 个百分点。
- 两个开发数据集上，家族上界为 96.195126%，相对当前 PDP 的最大剩余
  改进 ≤0.486826 个百分点，相对低参与统一 DP ≤0.469011 个百分点。

所以在上述固定家族内，即便完全消除噪声并理想优化，也不能再达到一次
宏平均增加 1 个百分点的改进。该结论涵盖盒内任意训练轨迹与噪声结果，
不依赖本次观察到的五个私有噪声实现。

**这没有证明不能取得任何正增益。** Facebook 等数据集仍有上界余量；
上界也不证明这些余量可实现。其他编码器、读出范围、模型 seed、GNN 家族
或扩散任务都不受此上界约束。不得将其宣传为所有 PDP 方法的效用不可能性。
当前实验的统计负结果与这里的家族限制是两类证据。

## 决策与可复核材料

继续在同一盒内改学习率、训练步数或反复抽噪声，无法突破该家族上界。
结合已经冻结的停止规则，维持当前开发线的 No-Go；新的模型家族需要
新的研究假设和预注册，不能通过更换测试协议掩盖当前负结果。
