# 基于 PrivIM 的个性化差分隐私影响力最大化：实现计划

日期：2026-10-26。状态：研究与实现路线，尚未实现 PDP，也未产生新的实验结果。

## 1. 结论与范围

建议在当前 PrivIM 复现代码上实现毕业论文题目
*GNN-based influence maximization with personalized differential privacy*，
以完整方法 **PrivIM*（SCS+BES，代码别名 `PrivIM+`）** 为主要统一 DP 对照。
基础 PrivIM 和 PrivIM+SCS 用于后续消融。

任务、GNN、损失和评估可以继承；隐私规范、机制及证明需要扩展。
“DP 改为 PDP”是问题定义上的变化，不能通过把标量 epsilon 改为向量就完成。
推荐顺序：**审计统一 DP 基础 → 实现节点级个性化抽样基线 → 验证 →
研究个性化 SCS/BES 增强 → 正式实验与论文撰写**。

本计划中的 PDP 指中心化、非有界节点级的个性化差分隐私。
不默认改成边级 DP、局部 DP 或联邦学习。

## 4. 首先固定 PDP 定义及发布对象

在公开的节点标识全集上定义外生预算映射
`Phi(v)=epsilon_v`，相邻图 `G ~_v G'` 只差节点 v 及其所有关联边、节点属性。
对每个 v、任意输出事件 O 及两个方向均要求：

```text
Pr[A(G) in O] <= exp(epsilon_v) * Pr[A(G') in O] + delta.
```

首版使用共同 delta，epsilon_v 越小保护越强。
预算映射作为固定外生策略，在比较相邻图时保留其他节点的预算不变。
真实偏好本身若也要保密，需要增加保护定义，首版不包含这一目标。

首版发布对象是训练后的 GNN 参数；在公开目标图上的推理可以作为后处理。
在另一张私有图上重新读取边和特征进行推理，并不自动保护该图。
若要在同一私有图上公开节点名单，必须另行分析整个种子选择机制；
在非有界节点邻接下，直接发布存在的节点 ID 还可能泄露节点是否存在。

复现实验中的 test 图用于统一效用评估，不能据此宣称其节点也获得训练集 PDP。
原始 loss、梯度范数、子图成员、频率、预算台账、数据相关 manifest 及随机种子
先作为可信环境内的诊断材料。正式发布格式必须单独界定，尤其不能公开
DP 噪声种子或用于隐私放大的节点入选随机性。

## 5. P0：先审计统一 DP 基础

以论文为规范，先解决以下证明前提；测试只用来查错，不能代替隐私证明。

1. **裁剪敏感度。** Appendix D、Equations (21)–(22) 从两个裁剪梯度
   推导 `C * Ng`。一般 L2 裁剪只能直接得到
   `||clip(g)-clip(g')|| <= 2C`；若要使用 C，需要证明变化确实是
   一条贡献相对于零的增删。原图删除节点可能改变仍存在子图的梯度，
   不能仅凭原图采用增删邻接就省略这一步。若需要修改常数，须重新标定噪声，
   明确这是对论文界的修正，而非直接声称论文就是 2C。
2. **采样稳定性。** Algorithm 3 的全局频率会影响后续游走。
   `f[v] <= M` 是单次运行的出现次数上界，不自动证明在 G/G' 上
   重新运行采样后只会改变 M 个子图。检查投影、游走、SCS、BES 的耦合，
   将“节点出现在多少个子图”和“删除节点改变多少个子图”分开。
3. **会计匹配。** 代码启动器默认 `paper_binomial`；论文 Theorem 3
   的二项式解释与 Algorithm 2 的固定大小批次存在已记录差异。
   应核对 Appendix E、两个方向的 RDP 和实际 batch law 后选择模式，
   不能直接把某种命名的 accountant 当成完整证明。
4. **数据相关参数。** 当前 delta、q、n、M、容器大小和噪声标定依赖节点数
   或采样结果。需要证明整个自适应机制满足共同界，或使用公开固定配置与
   公共规模上界；不能仅对一个固定采样容器给出条件会计。
5. **数据准备。** 固定基准 split 可用于效用比较，但原始图到 prepared 图的
   数据相关重划分、`active` 孤立节点删除、重编号不当然保持一节点邻接。
   首版明确保护对象从 prepared training graph 开始；若扩展到原始图，
   需补充稳定划分、标识映射及预处理证明。

验收：形成定义、敏感度、采样耦合、会计及发布边界的一致说明；
在路径图、星形图和小型有向图上检查反例。若出现次数界无法证明，
先使用固定 B、C、T、绝对噪声尺度和稳定空输入处理的保守训练机制：
每步裁剪梯度和范数最多 BC，因此两次结果之差可保守界为 2BC，
不依赖子图局部稳定性，也不使用该步骤的抽样放大。
该回退与论文 Equation (7) 不同，可能显著降低效用，需单列对照与限制。

## 6. P1：实现可证明的 PDP 抽样基线

暂名 `PDP-PrivIM-Sample`：在任何训练侧结构计算之前，按预算独立决定
训练节点是否参与，并只把保留节点的诱导图交给经过 P0 核验的统一 DP 训练器。

```text
原 prepared training graph + 外生预算映射
    -> 每个节点独立 Bernoulli(p_v)，仅进行一次
    -> 保留节点诱导图，移除未入选节点的全部关联边与属性
    -> 现有子图采样 + GNN 私有训练
    -> 训练参数 + 可信环境内隐私证书
```

设统一基础机制对所有可能的保留图都满足 `(epsilon_0, delta_0)` 节点 DP，
epsilon_0 为预先声明的公开阈值，delta_0 不超过共同目标 delta。选择：

```text
p_v = min(1, expm1(epsilon_v) / expm1(epsilon_0))
epsilon_bound_v = log1p(p_v * expm1(epsilon_0)) <= epsilon_v
delta_bound_v = p_v * delta_0 <= delta
```

这是基于 Poisson 抽样放大的候选构造。Balle 等的 Theorem 8 给出均匀
Poisson 抽样的界；这里非均匀概率和图诱导操作的节点级扩展应另写耦合证明：
固定其他节点的独立抽样结果，比较 v 是否保留造成的相邻诱导图，
再对其他节点的随机性取混合。不能不加说明地把表格记录定理套到图上。

执行前提与边界：

- 其他节点的入选概率不得随 v 的删除而变化。首版不按真实度数分配偏好，
  epsilon_0 也不能从当前私有图中观察到的最大预算临时选择。
- 可预设允许预算区间的上界为 epsilon_0；统一预算退化实验中令
  epsilon_0 等于该统一预算，此时所有 p_v=1，回到同配置的基础机制。
- 外层节点入选率记为 p_v，论文 RWR 起点采样率仍记为 q；两者不可混用。
  只降低 v 作为起点的概率，不能阻止它进入其他节点的子图。
- 首版外层只抽样一次，对整次训练的 DP 保证做一次放大；
  不在每个 iteration 重抽外层节点，也不再次乘 T。
- 抽样前不能利用完整私有图计算 degree 特征或其他会进入训练的结构量。
  保留 `ones` 特征可减少这类额外依赖。
- 空诱导图、无边图、子图数少于 B 必须定义为同一机制内的有效情况。
  禁止“反复抽样直到成功”或数据相关报错作为未经分析的发布行为。
- 第一版采用保守 `(epsilon, delta)` 放大；若之后改为个体 RDP 会计，
  必须重新推导，不能将 p_v 直接乘到现有 RDP 上。

该基线复用率高，但抽掉节点会损伤图结构；不预设它必然超过统一 DP。
这是后续结构保留增强是否有价值的实验依据。

## 8. P3：个性化 SCS/BES 增强研究

候选暂名 `PDP-PrivIM-Frequency`：用节点级出现上限 M_v 或参与约束，
在保留更多结构的同时满足各节点预算。优先研究出现次数约束，
暂不同时改变 GRAT、Equation (5) 或引入中心性加权目标。

需要先回答：

1. 同一子图含多个预算不同的节点，整个梯度的依赖和约束如何处理？
2. M_v 如何约束相邻图之间受影响的梯度数，而不只是本次实际出现次数？
3. 如何使用统一高斯噪声下、针对各 v 的双向隐私上界进行组合？
4. SCS 与 BES 如何共用节点级计数器，并在重采样后仍满足证明？

仅有 `f_v <= M_v`、按子图内最小 epsilon 选噪声、按 epsilon 比例取
M_v，均不足以直接宣称 PDP。若使用个体 RDP，形式应是对每个 v
建立每步有效界 rho_v,t(alpha)，再按实际 T 组合并转换，而不是事后
把观测频率代入全局 Equation (8)。

在证明成立且超预算数为零之后，再比较完整 SCS+BES 与只有 SCS。
若理论或试验不支持增强效果，保留 P1 的有效实现并如实报告限制，
不承诺该研究分支必定成功。

## 9. P4：正式实验设计

首轮预算为外生合成偏好，明确不代表真实用户调查。建议公开预注册：
统一预算对照，以及 epsilon_v 属于 `{1, 2, 4}` 的均衡、强隐私占多、
弱隐私占多三种分布；使用同一份节点预算映射比较所有方法。
之后再扫描预算整体尺度或连续分布，避免一开始组合爆炸。

| 方法 | 用途与合规定位 |
|---|---|
| Non-Private | 效用参照；不满足有限预算 PDP |
| 统一 DP，epsilon=min(epsilon_v) | 满足所有偏好的保守基线 |
| PDP-PrivIM-Sample | 首版个性化方法 |
| 经证明的 PDP-PrivIM-Frequency | 候选增强方法 |
| 统一 DP，epsilon=mean/max(epsilon_v) | 可选效用参照；一般不满足所有个人预算，明确标注 |

主比较是**相同逐节点隐私约束**下的效用，不能仅凭平均 epsilon 相同
称隐私公平。统一最小预算基线提供更强保护，应同时报告预算利用程度。

先 Email/Bitcoin，验证后扩展到六个数据集。所有方法共用原 prepared
train/test split、IC、边概率 1、1 hop、k=50、同一 CELF 分母。
仅训练视图因 PDP 机制变化；CELF 在共同完整 test 图上评估。
扩散参数或 k 的鲁棒性实验另列，不混入主表。

控制设置采用 `PrivIM复现.md` 的显式配置作为首轮经验起点：
lambda=0.5、私有 T=100、B=16、momentum=0、ones 特征、现有 GRAT，
非私有 T=500；固定其他论文/复现参数并保存。
若 P0 要求修正机制或参数，应在同一条件下补跑相关对照。
禁止按 test 效果为每个方法/数据集分别选最佳超参数。

报告项目：

- 影响力 spread、coverage ratio、五次运行均值及样本标准差、配对差值。
- 逐预算组 epsilon 理论上界/目标、最大比值、超预算节点数（必须为零）。
  台账中的 achieved epsilon 是理论会计上界，不是测得的真实隐私泄露。
- 节点/边保留率、训练子图数、预处理时间、实际更新次数、训练/推理时间和内存。
- 作为诊断报告 clipping fraction、top-k ties、失败运行；不删除低效用种子。

PDP 组指训练节点，原评估的种子来自 test 图；不能直接计算“训练隐私组
的 test 种子入选比例”。若研究群体公平性，须额外定义 test 分组及其意义。
度数相关预算仅作为后续结构相关压力实验，其隐私含义需另行解释。

可信运行元数据除原 n、theta、r、M、Ng、C、噪声、q、B、T 外，
补充保护对象、邻接定义、预算来源/映射指纹、epsilon_0、delta_0、p_v 策略、
保留图统计、基础证书版本、内外层会计方式及是否允许隐私声明。
正式公开导出不默认包含逐节点数据、实际频率、原始梯度或随机种子。
重复训练/调参若面向同一真实私有数据并发布多个结果，需要另算组合成本；
公开基准上的五次效用实验不能表述为只花费一次训练预算。

1. `PrivIM_Report.pdf`：II-B 保留非有界节点级邻接；III-C、Equation (5)
   继承 GNN 影响力损失；Algorithm 2、III-D、Equations (6)–(8)、Appendix D/E
   指导裁剪、敏感度及会计审计；IV、Algorithm 3 指导 SCS/BES；V-A
   指导统一评估。PDF 为本仓库原方法的主规范。
2. Jorgensen, Yu, Cormode，*Conservative or liberal? Personalized differential
   privacy*，ICDE 2015：外生个人隐私需求及抽样机制的基础来源。
   [作者接受稿记录](https://wrap.warwick.ac.uk/id/eprint/67370/)
   （本次取得出版记录和摘要，接受稿全文未成功加载，实施前补读具体定理）。
3. Balle, Barthe, Gaboardi，*Privacy Amplification by Subsampling: Tight Analyses
   via Couplings and Divergences*，NeurIPS 2018，Section 4、Theorem 8：
   Poisson 增删邻接下的隐私放大依据。
   [论文全文](https://arxiv.org/html/1807.01647)
   非均匀图节点版本是本计划需要补充的推导，不能冒称原文已经给出。
4. Yuan 等，*Personalized Differential Privacy Graph Neural Network*，
   IEEE/CAA JAS 2026，DOI 10.1109/JAS.2025.125279：已有 PDP-GNN 相关研究，
   出版方页面介绍预算分配与加权聚合。
   [出版方记录](https://www.ieee-jas.com/article/doi/10.1109/JAS.2025.125279?pageType=en)
   需进一步核对威胁模型与节点级定义后决定是否纳入可比基线，
   不能仅凭题目认定它与本题完全相同，也不能声称 PDP-GNN 本身是首次提出。

相对 PrivIM 的有意扩展包括：预算由统一标量变为外生节点映射、训练前
节点抽样和 PDP 证书、候选个性化 SCS/BES。lambda/T 沿用既有复现选择，
不作为论文公开常数。任何敏感度修正、保守回退、固定公开参数或稳定
预处理协议都需逐项记录其与原论文的差异及效用代价。
