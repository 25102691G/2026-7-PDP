# 读出层候选池的向外区间分析

本分析不训练、不调参、不更换任务，只解释已经冻结的正读出模型家族。
旧 `positive-head-expressivity` 结果保留；它使用的固定 1e-4 安全系数较松。
新分析以逐操作向外舍入替代该系数，不能把更精确的诊断称为新效用实验。

## 家族与排序界

在固定公开目标图和公共模型 seed 下，最后 fc 的输入为固定向量 z_i。
`LegacyGRATLayer.forward` 在最后线性层之前完成消息聚合；全部前层和注意力
已冻结，因此 z_i 与可训练读出 w,b 无关。logit 的实数模型为 w·z_i+b，
其中各 w_j 在固定区间 [l,u]，b 在 [-8,-1]。

两个节点 s,t 的共同 bias 抵消，精确的最小实数差为：

~~~text
D_min(s,t) = sum_j { l*(z_sj-z_tj), 若差≥0；
                    u*(z_sj-z_tj), 若差<0 }。
~~~

这是对整个盒的解析最小值，不是从若干训练参数的采样推测。
实现对二进制 float32 特征的精确 float64 表示做减法，并用 nextafter 向下
包络每次减、乘、加，获得不大于 D_min 的数值下界。

## 最后线性层的浮点余量

采用标准 FP32 乘加模型，单位舍入 u32=2^-24，不使用低精度替代、不溢出。
至多 q=2d+2 个舍入因子的连乘偏差由 gamma_q=q*u32/(1-q*u32) 界定。
对一个输出使用保守绝对误差：

~~~text
E_i = gamma_q * (u*sum_j |z_ij| + max(|b_lower|,|b_upper|)) + U；
U = 2q*2^-126。
~~~

U 额外覆盖细小项下溢/flush-to-zero；所有上界算术向 +infinity 包络。
该确定性 gamma 界的标准背景可核对
[Higham–Mary 原文的传统舍入分析说明](https://eprints.maths.manchester.ac.uk/2673/1/paper.pdf)。
这里不采用该文的概率性放松，也不将这个算术模型用于取代模型的隐私证明。

若 D_min 的下包络严格大于 E_s+E_t 的上包络，则所有允许权重下，
实际 FP32 logit_s 均大于 logit_t。不使用未证明的“相同特征总是相同内核舍入”
假设；不确定的同分关系均保留为可能竞争。

## 候选池与 Coverage 上界

固定一个大小 k 的参照集合 S（公开初始化的 Top-k）。若某个 t∉S 被全部
k 个 s∈S 普遍严格压过，则 t 不可能进入任何允许读出的 Top-k。
候选池 P 包含 S 和没有被上述规则排除的所有节点，故任意可能 Top-k 都包含于 P。

在 IC(p=1)、一步扩散下，所有 P 节点的覆盖并集是该家族任意 k 节点输出的
保守覆盖上界。它不要求这整个并集可由 k 个节点实现；除以 CELF 分母后，
上界可以超过 100%，此时不能误解为已经可取得该效用。
若 |P|=k，则该固定 seed 的整个盒家族 Top-k 不变；若上界仍松，只能报告不确定。

还可以保留固定核心 C：若 s∈S 普遍严格压过所有 S 外节点，则最多只有
k-1 个其他 S 节点可能排在 s 前面，所以 s 在所有 Top-k 中。
因此更紧的上界为：

~~~text
max { Coverage(C∪A) : A⊆P\C，|A|=k-|C| }。
~~~

此处忽略集合是否能被某个读出权重实现，故仍是乐观上界，不能当成新方法结果。
用整数 bitset 精确枚举组合，无浮点 coverage 误差。若组合数超过公开计算上限，
退回原候选池并集界并明确标记，不剔除该 seed。

范围：全部六个公开基准、所有 0..4 模型 seed，固定同一权重盒和当前数值环境。
不按观察到的结果缩窄盒或选择 seed。新结果不能证明其他 GNN/参数家族都不可能改进，
也不批准新增训练轮次；实验停止规则继续生效。
