# Node-PDP 实验预注册与发布边界

本协议在查看本阶段新 Coverage 之前写入，机器可读版本：
[pilot-v1.json](../configs/pdp/pilot-v1.json)。
原 prepared 数据、原划分、原代码和已有结果保持不变。
实验开始时记录协议内容 SHA-256、实现摘要和 prepared 文件摘要；
摘要只作为可信研究来源记录，不附加到任意私有输入的模型发布证书。

## 1. 前提与实验角色

先通过 [整数 B0 机制](b0_integer_privacy.md) 的代码验证和已有回归，
再运行预注册实验。噪声采用精确离散高斯；不使用原 PrivIM 的 M 会计。
首轮是 Email/Bitcoin 的公开开发基准，不把它们的测试图称为新的独立确认集。
其余四个数据集在该阶段不读取 Coverage；后续机制和参数须先锁定再确认。

协议不按测试 seed 搜索、删除异常 seed 或重跑较差结果。
模型 seed 固定 0..4，所有方法配对使用相同初始化；
预算政策、采样和 batch 种子固定。隐私噪声和外层参与随机性为新鲜秘密随机性，
不能要求其逐位复现，也不保存可重建它们的 seed。

## 2. 比较与公开参数

所有方法使用同一 prepared train/test、同一三层 GRAT、32 维 ones、
同一损失系数 0.5、学习率 0.005、batch=16 和 SCS+BES。
Email 子图 n=40、Bitcoin n=60，M=4；这是预先给定的共享参数，
不按方法或 seed 选择。非私有原解释用普通 SGD、T=500；
其余训练方法 T=100，额外增加裁剪零噪声控制以区分裁剪/噪声效应。
模型初始化控制不读取训练图。

| 方法 | 目的 |
|---|---|
| public_init | 数据独立模型，检查改善是否只是初始化/公开图结构带来的 |
| non_private | 无隐私普通 SGD 上参照，T=500 |
| clipped_no_noise | 与私有训练相同整数裁剪和固定 B，但不加噪，T=100 |
| uniform_dp | 经证明的 B0，epsilon_0=1、delta_0=10^-6 |
| pdp_base2 | 一次节点抽样+B0，基础 epsilon_0=2 |
| pdp_base4 | 一次节点抽样+B0，基础 epsilon_0=4 |

公共哈希策略为每个可能的稳定原 ID 定义预算组 {1,2,4}，
delta_v 共同取 10^-6，组选择与成员身份、度数、seed 和效果无关。
实际组比例可以偏离 1/3，不强制根据私有成员重平衡。
基础 epsilon_0=1/2/4 的比较必须保留，不能默认 4 最优。

## 3. 评估和报告

依论文 V-A：IC、边概率 1、一步扩散、k=50；
CELF 分母复用原 baselines.heuristics.greedy，所有方法共用同一目标图和分母。
模型按 logits 排序，同分用局部 ID 确定性打破；
不修改图、节点名单、扩散设置或标签来提高 Coverage。

每个方法记录全部五轮 spread、coverage、有限分数比例，
报告均值和样本标准差及配对差值。失败轮必须保留状态及原因；
不从汇总中静默剔除，不用成功轮替代失败轮。
实际参与节点/边数、子图数和梯度失败计数仅放可信诊断，
用于区分图结构损失、裁剪、初始化和噪声造成的失败。

## 4. 隐私证书范围

证书对应一次预先给定配置的训练调用；输入为 prepared training graph，
目标 test 图必须是固定公开辅助输入。它不保护私有目标图上的重新查询。
一个模型的 epsilon_v/delta_v 不能冒称整套实验或多模型发布的联合预算。

本轮数据是公开学术基准，非私有控制只在此环境运行。
模型及原始诊断留在可信研究目录，不自动发布全部训练产物。
真实私有部署禁止运行/公开 Non-Private 控制；
若要公开多个私有模型或据其分数选择模型，必须将全部相关调用组成一个机制，
逐节点组合其预算，或预先分配每次调用预算以满足同一总目标。
不能用“只公开最后选中的模型”规避选择成本。

按数据集调参是允许的，但需在新协议预声明候选和选择规则。
在真实私有数据上，配置选择必须来自独立公开验证来源，或计入组合的
私有选择机制；不能将观察到的私有验证效果伪称外生公共参数。
公开开发基准上形成的算法修改，须在未使用的确认数据集上锁定后检验。

## 5. 失败后的动作与停止规则

隐私合同失败立即停止，不能用更小噪声换 Coverage。
若梯度全部为零或非有限，先定位实现或数值问题。
若私有方法比 public_init 低至少 5 个百分点，先分析信号噪声和结构保留，
不把同配置矩阵扩展到六数据集。
后续最多两轮有独立理论/诊断依据的不同改进；若仍无至少 1 个百分点的
开发集平均改善，则停止无效搜索，保留全部结果并整理证据。
这不是保证两轮后一定达到论文效果，也不是允许按 seed 挑配置。

## 6. 首轮后的第 1 次机制修订：稳定公开槽位

首轮全部 60 单元完成后，记录其 [完整开发结果](pdp_pilot_v1_results.md)。
按原停止规则，不直接扩大原配置；改为已经给出
[双向证明](pdp_stable_slots_design.md) 的稳定槽位机制。
新预注册为 [stable-slots-pilot-v2.json](../configs/pdp/stable-slots-pilot-v2.json)。
不改变已完成首轮的协议、产物或选择其中某些 seed。

本轮仍只使用 Email/Bitcoin，模型 seed 全部为 0..4，T=100、C=3、
三层 GRAT、所有参数训练、lambda=0.5、学习率 0.005、内部 n=40/60 不变。
每步固定 4×4=16 个公开槽位，每槽位至多一个内部子图梯度。
隐私噪声与原节点抽样方案不同，使用新的逐节点改变槽位数证明，
不用外层抽样，也不把新参与上限误称为旧 SCS 频率保证。

| 方法 | 槽位参与上限，对应预算组 1/2/4 | 角色 |
|---|---|---|
| public_init | 不读取训练图 | 原单元逐模型校验后复用并重评估，不重新训练 |
| non_private | 原有 SCS/BES，T=500 | 复用同配置的已完成上参照，不重跑已有结果 |
| slots_zero_noise | 1/2/4 | 与新 PDP 相同梯度查询和 T 的零噪声控制，无 DP 声明 |
| uniform_dp | 1/1/1 | 新槽位机制的统一 epsilon=1 对照 |
| uniform_full | 4/4/4 | 全参与、统一 epsilon=1 的另一对照，防止只选择较弱基线 |
| pdp_slots | 1/2/4 | 逐节点 epsilon=1/2/4、delta_v=10^-6 的直接 PDP |

共 60 个评估单元，其中 20 个已完成控制模型复用，40 个新训练调用。
只有公共初始化和明确非私有的控制可以复用：要求原运行全部完成，执行过的
基线依赖源码、参数配置、运行环境、prepared 摘要及模型文件摘要完全匹配。
两个运行目录各自保留，参考目录不写入；新目录显式记录复用来源和零新增调用。
不能对任意不同配置借用一个效果较好的旧模型。

目标图、IC、k、CELF 分母及 logits 同分规则仍完全一致。
全部五轮结果、标准差、配对差值和失败状态都保留。对 PDP 同时比较两种统一 DP
及前轮 base2 的开发集平均，不能只报告其中有利的对照。
非私有 T=500 是原上参照；slots_zero_noise 才是新 T=100、同槽位的匹配控制。

编码核验发现并处理了两个必要边界：槽位图按稳定 ID 与边端点规范排序，
以免纯局部重编号改变未受影响查询；一个槽位的异常只回退该槽位，不能清空
所有槽位。含这些不变量及旧回归的完整 107 项检查通过（18.036 秒）。
运行开始时冻结新协议、实现、数学证明与 prepared 摘要；只运行 CPU。
这只是最多两次有依据机制修订中的第 1 次，不是放弃无进展停止规则。

## 7. 第 2 次及最后一次开发修订：公开编码器与私有读出

第二轮全部结果及不继续扩大配置的理由见 [v2 结果](pdp_slots_v2_results.md)。
新机制的 [数学规范](pdp_positive_head_design.md) 先于实现及新 Coverage 写明；
机器预注册：[positive-head-pilot-v3.json](../configs/pdp/positive-head-pilot-v3.json)。

仍只使用两个开发数据集及全部 seed 0..4。固定公开编码器和注意力，
仅训练 33 维读出层，整数噪声仍按 2M_v C、全部 T 校准，不因降维再减小尺度。
每步盒投影是噪声轨迹后处理。学习率改为统一 0.0001，所有参数与约束
对全部 dataset/seed 相同；没有预览新公开编码器在真实基准上的 Coverage 后再选择。

本轮 50 个单元全部新评估，包括同一公开编码器初始化、匹配裁剪零噪声
Non-Private T=100、uniform_low、uniform_full、个性化槽位。
不复用先前编码器不同的控制模型。原全参数 Non-Private T=500 只作历史上参照。

预设进入四数据集确认的工程关口：PDP 两开发集等权平均至少 68.64345%，
各开发集均值至少 70%、各开发集样本标准差至多 10%。这不是统计显著性或
非劣检验，也不单凭它声称个性化优于统一 DP。仍必须报告相对公开初始化、
匹配 Non-Private、两种统一 DP 的全部比较，包括没有优势的结果。

若关口失败，不再开发搜索；若通过，先冻结单独的确认协议，再读取 LastFM、
HepPh、Facebook、Gowalla 的新 Coverage。确认阶段不调整机制或根据 seed 重试。
代码核验已包含冻结参数不变、真实非零读出梯度、相同噪声尺度、整数加噪与
公共盒投影、匹配控制及恢复。全部原有与新增 119 项检查通过。

## 8. 冻结的四数据集确认

v3 的 50 个单元全部完成。PDP 开发集均值 95.7083%；Email 为
93.0556±0.0000%，Bitcoin 为 98.3610±0.0797%，通过预设工程关口。
公开初始化约为 93.0556% / 98.3967%，统一 DP 也基本持平。
因此目前效用稳定化主要来自公开编码器，尚无个性化学习额外收益的证据；
这一事实不影响隐私证明，也不得在后续报告中省略。

在读取新机制的四个确认数据集 Coverage 前，冻结
[positive-head-confirmation-v1.json](../configs/pdp/positive-head-confirmation-v1.json)。
LastFM、HepPh、Facebook、Gowalla 全部固定 n=40；其余模型、参数、预算、
槽位、特征、扩散、k、学习率、T 和全部 seed 与 v3 相同，不再调参。
额外保留全参与 4/4/4 的零噪声控制；它不影响模型选择或 PDP 的隐私预算。
共 4×6×5=120 个评估单元，所有结果和失败状态保留。

开发之后源码只补充公共证书的 n/theta/r/M/Ng/q 规则及可信诊断中的实际逐槽位 q，
没有改变计算梯度、槽位采样、加噪或更新路径。新源码与证明仍在运行前归档。
当前单线程 CPU 限制被入口显式检查，不套用到未审查的 GPU 并行实现。
确认完成后仅分析和报告，不继续以确认结果选择架构、参数、seed 或噪声。
