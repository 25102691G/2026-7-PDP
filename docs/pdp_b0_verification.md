## 证明到代码的逐项对应

| 合同 | 当前代码与证据 | 判定 |
|---|---|---|
| 无界节点增删，删除属性和全部关联边 | `personalization.sample_nodes_once` 使用诱导图；稳定 ID 不随局部重编号改变；测试覆盖存活属性、边和孤点 | 满足 |
| 固定公共 B/C/T/维度/噪声 | `RangePrivacy`、`TrainingConfig`；标定不接收节点数、容器大小或频率；架构只有公共维度 | 满足 |
| 精确梯度范围 | `quantize_gradient` 后以整数平方和及 `project_integer_ball` 强制半径 R；非有限贡献为零；`sum_contributions` 限制最多 B 项 | 满足 |
| 正确敏感度 | 和为 2BR，物理均值至多 2C；不使用 M 或子图放大；对任意两输入及隐藏状态都成立 | 双向证明见整数设计第 2–3 节 |
| 噪声概率核 | `discrete_noise.py` 以整数/Fraction 实现 CKS Algorithms 1–3；无近似 exp、无拒绝次数上限 | 代码与所引精确算法对应 |
| 新鲜秘密噪声 | 生产入口仅用 `secrets.randbelow`，没有噪声 seed 参数；外层抽样使用独立新鲜调用 | 依赖秘密、独立、无偏系统随机位的明确模型 |
| 加噪顺序 | 整数贡献求和、整数噪声相加，再公共截断、转浮点和固定 B 平均 | 满足；测试包含超过浮点整数精度的噪声 |
| 全部诱导图 | 空图、无边图、少于 B 项均合法；预处理/梯度异常内部回退零；仍执行 T 次加噪 | 满足；固定循环代码与专项检查一致 |
| 条件组合 | 任意历史及两侧隐藏容器后验均受同一 2BR 范围界；T 次 RDP 相加；所有参数更新是噪声轨迹后处理 | 完整双向证明已给出 |
| 标定的数值方向 | Fraction 表示 rho，Decimal 向外包络 ln/sqrt，只有 epsilon 上界不超过目标才接受整数噪声尺度 | 满足；与更高精度计算核对 |
| 仅认证参数导出 | `ParameterRelease` 和 `save_release` 仅含固定形状 state_dict 与公共证书；无原始训练统计、掩码和噪声 seed | 满足；原始诊断只能留在可信环境 |
| 一次外层抽样 | `train_pdp` 在整个 `train_b0` 之前只调用一次 sampler；不逐步重复放大 | 满足 |
| 每节点 epsilon/delta | p 向下包络 epsilon 比且不超过精确 delta 比；最终界为 log(1+p(expm1(epsilon_0)))、p delta_0 | 满足；两个方向的证明见 P0 PDP 报告 |
| 外生预算 | 当前实验按公开固定 SHA256 策略在所有可能整数 ID 上赋组，不读取私有度数或当前成员最大预算 | 满足当前实验；不宣称这是用户真实偏好调查 |
| 推理发布边界 | `evaluation.py` 只能使用固定公开目标图；重新读取受保护图不在证书内 | 明确限制 |

确切证明见 [整数 B0](b0_integer_privacy.md)、

## 核验范围及限制

现有记录 `/tmp/pdp_preexperiment_tests.log`：完整 95 项检查通过，18.081 秒。
相应源码与当前及预注册运行保存源码相同，本轮没有为重复取得绿色结果而重跑。
已逐项阅读新增专项检查，包括非零真实 GRAT/Equation (5) 梯度、整数范围、
空输入、内部失败、固定 T、加噪顺序、参数导出、一次外层抽样和恢复行为。
已完成的 16 个私有试验单元诊断均为 T=100、无预处理失败、无异常梯度回退；
存在非零贡献。这只说明这些实际运行符合所检查合同，不代替全域证明。

模型证书只适用于一次预先给定配置的训练调用；公开整个研究目录、多个
模型或基于私有验证集选择模型，不能沿用单模型预算。当前全部试验是公开基准，
原始诊断与模型集中放在 `trusted/`。真实私有部署须隔离整个训练过程的计时、
错误、原始日志、临时文件及数据输入，只通过参数导出边界发布。

当前保护边界从逻辑 prepared training graph 开始；不继承认证原始切分脚本，
不保护目标 test 图，也不把公开基准的现有 split 视为新采样的私有数据发布。
当前哈希预算策略是预先固定的异质预算实验；任意真实偏好接口仍须保持外生性。
